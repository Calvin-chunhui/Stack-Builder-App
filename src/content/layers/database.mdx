A database stores information so it's still there after people leave: accounts, orders, messages. Relational (SQL) databases keep data in tables with fixed columns that link together, a bit like connected spreadsheets. Document (NoSQL) databases store flexible JSON-like records. Most new apps start with PostgreSQL.
