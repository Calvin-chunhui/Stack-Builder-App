Mobile apps are downloaded from the Apple App Store or Google Play and run directly on the phone. Native apps are written separately for each platform (Swift for iPhone, Kotlin for Android). Cross-platform tools like React Native and Flutter let one codebase produce both. Apps still talk to a backend or a service like Supabase to save data.
